# INVERSION: Echoes of Two Worlds

**A 2D Dark Fantasy Platformer | Hackathon Project**

INVERSION: Echoes of Two Worlds is a 2D dark-fantasy platformer built around a unique gravity-inversion mechanic. Explore mysterious environments, navigate dangerous platforms, and experience two contrasting worlds where the laws of gravity can be reversed.

Our goal is to create an atmospheric, engaging platforming experience that combines exploration, movement, combat, and a world shaped by inversion.

## 🎮 Game Overview

In a fractured world where reality has lost its balance, the player must navigate mysterious ruins and dangerous environments by mastering the power of gravity inversion.

Flip gravity to overcome obstacles, discover new paths, and explore a world where the ground and ceiling can exchange roles.

### ✨ Key Features

- **Gravity Inversion:** Reverse gravity to navigate the environment in unconventional ways.
- **2D Platforming:** Move, jump, and traverse challenging platforms.
- **Dark Fantasy Atmosphere:** Explore mysterious ruins and visually distinctive environments.
- **Dual-World Concept:** Experience contrasting realms inspired by the theme of inversion.
- **Exploration and Challenges:** Navigate obstacles and discover new routes.
- **Ongoing Development:** Designed to support future levels, enemies, combat, upgrades, animations, and sound effects.

*Note: Features may vary depending on the current implementation of the game.*

## 🚀 Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm.

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd YOUR_PROJECT_FOLDER
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal to access the application.

### Production Build

To create a production build, run:

```bash
npm run build
```

If the build succeeds, the generated files will be available in the `dist` directory.

## 🎯 Project Theme: INVERSION

The game explores the concept of **inversion** by challenging a fundamental rule of platforming: gravity.

Instead of treating the ground as the only safe surface, the player can use gravity reversal to rethink movement, navigation, and interaction with the environment.
